# 포켓몬 랜덤 디펜스

랜덤 소환으로 포켓몬을 모아 포켓몬 리그 챔피언이 되는 디펜스 게임이에요.
설치 없이 브라우저에서 바로 해요.

**바로 하기: https://donkochu.github.io/pokemon-random-defense/**

## 하는 법

- 첫 파트너를 고르고 코인으로 포켓몬을 소환해요. 알이 빛나는 색이 등급이에요.
- 같은 계열 3마리를 미라클 교환하면 한 등급 위 포켓몬이 와요.
- 배틀칸 6마리만 싸워요. 웨이브마다 바뀌는 적 타입에 맞춰 바꿔 끼워요.
- 10웨이브마다 관장과 싸우고, 배지 8개를 모으면 포켓몬 리그로 가요. 130웨이브 챔피언까지 이기면 엔딩이에요.
- 필드에 적이 40마리 쌓이면 패배예요.

단축키: Space 소환, 1 2 3 볼, 4 도전, 5 진화, 6 교환, Esc 멈춤. 오른쪽 위 톱니바퀴에서 소리와 화면을 설정해요.

## 만든 사람과 출처

- 만든이: 방구석평론가
- 엔진: GameMaker
- 포켓몬 그림: Pokémon Essentials 그래픽 묶음
- 배경 그림: Google Gemini
- 음악과 효과음: 8비트 원곡

비공식 팬게임이에요. 닌텐도, 게임프리크, 포켓몬컴퍼니와 관계없고 돈을 받지 않아요.
