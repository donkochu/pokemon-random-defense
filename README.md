# 포켓몬 랜덤 디펜스

랜덤 소환으로 포켓몬을 모아 포켓몬 리그 챔피언이 되는 디펜스 게임이에요.
설치 없이 브라우저에서 바로 해요.

**바로 하기: https://donkochu.github.io/pokemon-random-defense/**

게임 소개와 하는 법: https://donkochu.github.io/pokemon-random-defense/guide/

## 하는 법

- 첫 파트너를 고르고 코인으로 포켓몬을 소환해요. 알이 빛나는 색이 등급이에요.
- 같은 계열 2마리를 미라클 교환하면 한 등급 위 포켓몬이 와요.
- 소환 강화로 소환 레벨을 올리면 영웅이 잘 나와요. 전설은 5레벨부터 조금씩 나오고, 하이퍼볼은 배지 8개를 모으면 던질 수 있어요.
- 팀이 모이면 플레이트로 타입별 공격력을 올려요.
- 배틀칸 6마리만 싸워요. 웨이브마다 바뀌는 적 타입에 맞춰 바꿔 끼워요.
- 10웨이브마다 관장과 싸우고, 배지 8개를 모으면 포켓몬 리그로 가요. 130웨이브 챔피언까지 이기면 엔딩이에요.
- 관장을 이기면 정비 시간이에요. 포켓몬을 정리하고 시작(Enter)을 누르면 다음 스테이지로 넘어가요.
- 필드에 적이 40마리 쌓이면 패배예요.

단축키: Space 소환, 1 2 3 볼, 4 도전, 5 진화, 6 교환, Enter 정비 끝내기, Esc 멈춤. 오른쪽 위 톱니바퀴에서 소리와 화면을 설정해요.

## 폰에서 하기

- 폰 브라우저로 열면 폰용 화면으로 바뀌어요. 세로와 가로 모두 돼요.
- 포켓몬을 누르면 PC칸 자리에 정보와 진화, 교환, 판매 버튼이 나와요. 닫기나 빈 필드를 누르면 PC칸으로 돌아가요.
- 앱처럼 설치할 수 있어요. 처음 들어가면 하는 법이 떠요. 아이폰은 공유 버튼 → 홈 화면에 추가, 안드로이드는 앱으로 설치 버튼이나 브라우저 메뉴 → 홈 화면에 추가예요. 설치하면 주소창이 없어져서 게임 화면이 더 커지고, 홈 화면 아이콘으로 바로 열려요. 앱 스토어 없이 설치되고 항상 최신 버전이에요.
- 처음 열 때 30MB쯤 받아요. 와이파이에서 여는 게 좋아요.

## 만든 사람과 출처

- 만든이: 방구석평론가
- 엔진: GameMaker
- 포켓몬 그림: Pokémon Essentials 그래픽 묶음
- 배경 그림: Google Gemini
- 음악과 효과음: 8비트 원곡

비공식 팬게임이에요. 닌텐도, 게임프리크, 포켓몬컴퍼니와 관계없고 돈을 받지 않아요.
